# Ayra Discord Bot - Legal Website Template

A modern, highly polished, glassmorphism-styled website for your Discord bot **Ayra**, featuring separate pages for Terms of Service and Privacy Policy, smooth Dark/Light mode toggle, and direct support server integration.

## 🚀 How to Deploy on GitHub Pages

1. **Upload Files:** Upload `index.html`, `privacy.html`, `icon.png`, and `banner.png` directly to your GitHub repository root.
2. **Add Bot Images:** 
   - Rename your bot's icon image to `icon.png`.
   - Rename your bot's banner image to `banner.png`.
3. **Enable GitHub Pages:**
   - Go to your repository **Settings** -> **Pages**.
   - Under **Build and deployment**, select Branch: `main` and Folder: `/ (root)`.
   - Click **Save**.

## 🔗 Live URLs for Discord Developer Portal

- **Terms of Service:** `https://<your-username>.github.io/<repository-name>/`
- **Privacy Policy:** `https://<your-username>.github.io/<repository-name>/privacy.html`
