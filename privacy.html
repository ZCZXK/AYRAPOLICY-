Privacy Policy

Effective Date: September 4, 2026

1. Information We Collect

To provide core moderation, utility, and interactive features, Ayra collects minimal essential data from Discord, including:

  • Identifiers: Discord User IDs, Server (Guild) IDs, and Channel IDs.
  • Server Configurations: Custom server settings, prefix configurations, roles, and feature toggles selected by administrators.
  • Command Telemetry: Anonymized command execution logs used exclusively for error diagnostics and bot stability.

Note: Ayra does not process or store private message contents or voice data.

2. How We Use Collected Data

All data collected is strictly utilized to operate and improve Ayra's service. Specifically:

  • To persist server configurations and user settings across bot restarts.
  • To enforce rate limits and prevent automated spam or abuse.
  • To identify and patch operational bugs or system downtime.

We do NOT sell, lease, trade, or share any user or server data with third-party advertisers or commercial entities.

3. Data Retention & Security

Your server data is retained only as long as Ayra remains in your Discord server or as needed to maintain active settings. All stored data is secured using industry-standard database encryption and access controls.

4. Data Deletion & User Rights

Server administrators or users can request the permanent removal of stored data associated with their User ID or Server ID. To submit a data deletion request, join our Support Server and create a support ticket.

5. Updates to This Policy

We may periodically update this Privacy Policy to reflect changes in our operational features or legal compliance. Continued use of Ayra after updates implies acceptance of the revised policy.
